📋 프로젝트 소개

HanaZoom은 지역별 주식 투자 트렌드를 한눈에 보여주는 지도 기반 웹 서비스입니다.

🏗️ 주요 기술 스택

분야 기술 스택
Frontend Next.js, TypeScript, TailwindCSS, Kakao Maps API, Zustand, WebSocket
Backend Spring Boot, Spring Security + JWT, JPA(Hibernate), WebSocket, REST API
Database MySQL (지역/주식/회원/커뮤니티), MongoDB (채팅), Redis (캐시)
Infra Docker, Docker Compose, Kafka, Elasticsearch, Kibana

✨ 주요 기능

  • 지도 기반 시각화: 카카오 지도 API를 이용한 시/구/동 단위 행정구역 표시
  • 실시간 데이터: 지역별 인기 주식 순위와 실시간 주식 데이터 (5분 주기 갱신)
  • 커뮤니티 기능: 지역 채팅방, 종목별 게시판, 투표 기능
  • 개인화 서비스: 회원가입/로그인을 통한 맞춤형 투자 정보 제공

🔧 전제조건

필수 요구사항

  • 운영체제: Windows 10+, macOS 10.15+, Linux (Ubuntu 18.04+ 권장)
  • 메모리: 최소 8GB RAM (16GB 권장)
  • 디스크 공간: 최소 10GB 여유 공간
  • Node.js: 18.x 이상
  • Java: 17 이상 (Spring Boot용)
  • Docker: 20.10 이상
  • Docker Compose: 2.0 이상
  • Python: 3.8 이상 (데이터 스크립트용)

🔑 API 키 준비 (선택사항)

실시간 주식 데이터와 지도 기능을 위해 다음 API 키들이 필요할 수 있습니다:

  • 카카오맵 API 키: 지도 서비스 이용을 위해
  • 카카오 REST API 키: 주소 변환 기능 이용을 위해
  • 한국투자증권 API 키: 실시간 주식 데이터 수집을 위해

💡 Python 설치 방법

Python이 설치되어 있지 않은 경우:

2단계: pip 업그레이드 및 가상환경 설정

# pip 업그레이드

python -m venv hanazoom-env

# 가상환경 활성화 (Windows)
hanazoom-env\Scripts\activate

# 가상환경 활성화 (macOS/Linux)
source hanazoom-env/bin/activate

주식 로고 업데이트 스크립트 패키지

분봉 차트 데이터 스크립트 패키지

cd scripts/stock_minute_chart

설치되는 패키지: requests, pandas, mysql-connector-python, tqdm, schedule

일/주/월 차트 데이터 스크립트 패키지

cd scripts/stock_daily_weekly_monthly_chart

설치되는 패키지: pykrx, pandas, tqdm, tenacity, mysql-connector-python

✅ 주요 패키지 설명

  • mysql-connector-python: MySQL 데이터베이스 연결
  • requests: HTTP API 호출
  • pandas & numpy: 데이터 처리 및 분석
  • pykrx: 한국투자증권 주식 데이터 수집
  • tqdm: 진행률 표시
  • tenacity: 재시도 로직 구현

📦 설치 방법

1단계: 프로젝트 클론

git clone <your-repo-url>
cd HanaZoom

2단계: 환경 설정 파일 생성

프론트엔드 환경 변수 파일 생성:

# FE/.env.local 파일 생성
# API 서버 설정
NEXT_PUBLIC_API_URL=http://localhost:8080

# 카카오 API 설정 (필요시 발급받아야 함)
NEXT_PUBLIC_KAKAO_MAP_API_KEY=your_kakao_map_api_key
NEXT_PUBLIC_KAKAO_REST_API_KEY=your_kakao_rest_api_key

# 개발 환경 설정
NODE_ENV=development

3단계: 인프라 서비스 실행

cd Infra
docker-compose up -d

실행되는 서비스들

  • MySQL (3306): 메인 데이터베이스
  • Redis (16380): 캐시 서버
  • MongoDB (27017): 채팅 기록 저장
  • Elasticsearch (19200): 검색 엔진
  • Kafka + Zookeeper: 메시지 큐
  • Kibana (15601): Elasticsearch 대시보드

4단계: 데이터베이스 초기 데이터 설정

프로젝트의 기본 데이터를 데이터베이스에 입력합니다:

기본 주식 및 지역 데이터 입력

mysql -h localhost -P 3306 -u hanazoom_user -p hanazoom
source scripts/region_data/insert_stocks_domestic.sql;
source scripts/region_data/update_stocks_with_logo_urls.sql;
exit;

테스트 사용자 데이터 입력 (선택사항)

mysql -h localhost -P 3306 -u hanazoom_user -p hanazoom
source scripts/user_creation/cheongra_users_insert.sql;
exit;

📊 입력되는 데이터 종류

  • 국내 주식 종목: 약 500개 주요 종목 데이터
  • 지역별 정보: 시/구/동 단위 행정구역 데이터
  • 테스트 사용자: 약 1,000명의 테스트 사용자 계정

📊 데이터 수집 스크립트 실행

⚠️ 데이터 수집 전 주의사항

  • 가상환경이 활성화되어 있어야 합니다
  • MySQL 데이터베이스가 실행 중이어야 합니다
  • 한국투자증권 API 키가 설정되어 있어야 합니다

1단계: 지역별 행정구역 데이터 생성

GeoJSON 파일을 기반으로 지역별 행정구역 데이터를 생성합니다.

2단계: 기본 주식 데이터 입력

mysql -h localhost -P 3306 -u hanazoom_user -phanazoom1234!
USE hanazoom;
source scripts/region_data/insert_stocks_domestic.sql;
exit;

3단계: 주식 로고 URL 업데이트

cd scripts/stock_logo
python stock_logo_updater.py

주식 종목들의 로고 이미지 URL을 업데이트합니다.

4단계: 분봉 차트 데이터 수집

cd scripts/stock_minute_chart
python fetch_minute_data.py

예상 소요 시간: 2-3시간
수집 데이터: 97개 종목의 1분봉, 5분봉, 15분봉 데이터 (최근 30일)

5단계: 일/주/월 차트 데이터 수집

cd scripts/stock_daily_weekly_monthly_chart

예상 소요 시간: 30분-1시간
수집 데이터: 100개 주요 종목의 일별/주별/월별 데이터

6단계: 수집된 데이터를 데이터베이스에 저장

cd scripts/stock_daily_weekly_monthly_chart
python process_stock_data.py

CSV 파일로 수집된 데이터를 MySQL 데이터베이스에 저장합니다.

7단계: 실시간 분봉 데이터 업데이트 시작

cd scripts/stock_minute_chart
python realtime_updater.py

실행 주기: 1분봉(1분), 5분봉(5분), 15분봉(15분)
거래시간: 평일 09:00 ~ 15:30 자동 감지

🔧 문제 해결

🚨 Docker 서비스가 시작되지 않는 경우

# 로그 확인
docker-compose logs [서비스명]

# 특정 서비스 재시작
docker-compose restart [서비스명]

# 모든 서비스 재시작
docker-compose down
docker-compose up -d

🚨 백엔드 빌드 오류

cd BE/HanaZoom
./gradlew clean build

Java 버전이 17 이상인지 확인하세요.

🚨 데이터베이스 연결 실패

  • MySQL: 사용자명 hanazoom_user, 비밀번호 hanazoom1234!
  • MongoDB: 사용자명 hanazoom_mongo, 비밀번호 mongo1234!
  • Redis: 비밀번호 redis1234!

🚨 기본 데이터 입력 실패

SQL 파일 경로가 올바른지 확인하고, 데이터베이스 권한을 확인하세요:

# 파일 경로 확인
ls -la scripts/region_data/
ls -la scripts/user_creation/

# MySQL 권한 확인
mysql -h localhost -P 3306 -u root -p
GRANT ALL PRIVILEGES ON hanazoom.* TO 'hanazoom_user'@'%';

🚨 포트 충돌

다른 서비스가 포트를 사용 중인 경우 다음 명령어로 확인하고 종료하세요:

lsof -i :[포트번호]
kill -9 [PID]
